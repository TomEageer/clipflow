# Clipflow

**能把你复制的东西原样还给你的 macOS 剪贴板管理器**

大多数剪贴板工具只留文字，其余的悄悄丢掉。<br>
Clipflow 保存剪贴板提供的**每一种格式**——所以富文本粘回去还带格式，
一次复制三个文件粘出来还是三个，**逐字节和原来一样**。

[English](README.md) · [更新日志](CHANGELOG.md) · [赞赏支持](DONATE.md)

## 为什么做这个

- **保真，不只是文本** —— 一次复制是一个 `NSPasteboardItem` 上挂着好几种 UTI
  （`public.rtf`、`public.html`、`public.utf8-plain-text`，还有各家 App 的私有格式）。
  Clipflow 全部存下来、全部写回去。从文档里复制带格式的文字，粘到另一个文档，格式还在。
- **多文件复制不塌陷** —— 复制三个文件就是三个文件。剪贴板的多 item 结构被完整保留，
  不会被拍平成一个。
- **中文搜索是真能用的** —— FTS5 自带分词器把连续汉字当成一个词元，搜「订单」
  匹配不到「订单支付回调」。Clipflow 在应用层做 bigram 分词 + 短语查询，精度才立得住。
- **规模上去也不慢** —— 100 万条实测 518 MB，检索 P95 0.27 ms，**不随规模劣化**。
- **天然隐私** —— 没有任何联网代码，没有埋点，没有账号。密码管理器复制的内容永不记录。

## 快速开始

```bash
git clone https://github.com/TomEageer/clipflow.git
cd clipflow
./scripts/build-app.sh
open build/Clipflow.app
```

需要 macOS 14+ 与 Xcode 命令行工具。菜单栏出现图标即可用。

| 操作 | 按键 |
|---|---|
| 在鼠标旁唤出面板 | **⌘⇧V**（可自定义） |
| 搜索 | 直接打字 |
| 移动 / 粘贴 | **↑↓** / **⏎** |
| 直选第 N 条 | **⌘1** … **⌘9** |
| 置顶 / 删除 | **⌘P** / **⌘⌫** |
| 关闭 | **esc** 或点面板外面 |

自动粘贴需要「辅助功能」权限（系统设置 → 隐私与安全性 → 辅助功能）。
**不给权限也能用**——内容会放进剪贴板，你手动 ⌘V，而且会明确告诉你，不会默默失败。

## 面板

面板开在鼠标旁边——跟随鼠标的意义就是让鼠标少动。
到屏幕右边缘时面板只能开在鼠标左侧，这时它的两栏会**左右对调**，
让可点击的列表始终贴着鼠标那一侧。

右侧预览显示完整文本、缩放后的图片，以及这一条到底存了哪些格式、各多大——
保真是这个项目的卖点，就该看得见。

## 实现要点

macOS **没有剪贴板变更通知**——没有 `NSNotification`、没有 KVO、没有回调。
唯一可行的是轮询 `NSPasteboard.general.changeCount`（活跃时 200ms，
系统空闲一分钟后降到 1s）。

真正有意思的是"读内容"这一步，几个决定都是被实测逼出来的：

- **读取必须与检测同步。** 剪贴板内容是瞬态的，系统只保存"当前"一份。
  延后读取时若剪贴板已翻页，读到的是新内容却被记在旧那次变更上。
  实测：连续复制 7 次，异步读把后 5 次全读成了最后一条。
  **漏记可以接受，记错不行。**
- **有些类型会阻塞几十秒。** 承诺型（promised）类型如果拥有者从不兑现，
  读取会一直等到系统超时。Clipflow 为此保留了看门狗和自学习负缓存——
  但常规路径仍然读全部类型，因为跳过一种类型就是丢一份保真度。
- **绝不 `ORDER BY rank`。** 排序打分要给每一条命中算分：2 万条命中 46ms，
  而按时间倒序只要 0.30ms——**而且剪贴板用户要的本来就是"最近的"**。又快又更对。

存储用 GRDB + SQLite：内容库、**独立的**索引库（索引可以整体重建而不动内容）、
以及内容寻址的附件存储（同一张图复制 100 次只占一份磁盘）。

## 架构

```
ClipflowCore      核心引擎 —— 零 UI 依赖，有测试硬性保证
ClipflowCapture   唯一允许 import AppKit 的非 UI 目标
ClipflowApp       菜单栏 App
clipflow          命令行 —— 同时也是"核心真的解耦了"的证明
```

命令行不是附赠功能。`clipflow search 订单` 能跑通，就证明 Core 没有偷偷依赖 UI。

## 实测性能

M4 Pro，48000 条：

| 操作 | 中位 | P95 | 预算 |
|---|---|---|---|
| 列出最近 20 条 | 0.09 ms | 0.11 ms | — |
| 中文短语检索 | 0.16 ms | 0.19 ms | 16 ms |
| 标识符检索 | 0.45 ms | 0.55 ms | 16 ms |

扩到 100 万条：总计 518 MB，检索 P95 0.27 ms——**是平的，不是线性增长**。
文中每个数字都能用 `bench/` 里的脚本复现。

## 隐私

所有数据只在你的 Mac 上。这个项目里没有任何联网代码。

- 尊重 `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType`，
  另有 1Password / Bitwarden / LastPass / Dashlane / KeePassXC 等 bundle id 黑名单
- 匹配 JWT / AWS 密钥 / 私钥 / `password=` 等模式的内容会被标记为敏感，
  **不进搜索索引**，并按短 TTL 自动销毁
- 数据库文件权限 `600`，目录 `700`
