## Where the money goes · 用途

Clipflow has no running costs beyond the developer's time. Tips go toward:

- an Apple Developer account ($99/year) so releases can be signed and notarized —
  this removes the "unidentified developer" warning for every user
  （Apple 开发者账号，用于签名与公证，去掉所有用户首次打开时的安全拦截）
- test machines on other macOS versions to catch pasteboard behaviour differences
  （其他 macOS 版本的测试机，剪贴板行为在不同系统上有差异）

No donation is ever required to use any feature. 所有功能永久免费，捐赠完全自愿。
